## 8. Pitfalls learned
- Generic from earlier chats: `check_design.py` prefix→owner map (keep `repo:` in `app-meta.js` accurate — it is `'tickler'` here); old-style service workers wiped sibling caches; brand-tagline media rule must come after `.brand__sub`; guard `classList` changes inside the body MutationObserver; alias tokens rather than importing starter component CSS into older apps; Companion apps now default to match-device.
- Batch Tickler: **all code shares one big closure in js/app.js — a new top-level `function x()` silently replaces an older one with the same name** (1.21.0 first shipped `markSeen` and `snippet` twice, breaking the Met-everyone badge and search suggestions; caught by f114). Prefix new helpers (`chat…`) and run the duplicate check: `grep -oE "^  function [A-Za-z0-9_]+\(" js/app.js | sort | uniq -d` must print nothing. Elements with the `hidden` attribute that also have `.btn` stay visible (`.btn{display:inline-flex}`) — add a `[hidden]{display:none}` rule. Never reuse `.today__q` for a new Home card — `today_test.py` reads the first one (QOTW uses `.qotw-q`). Radio defaults: an unset choice must start unchecked (the truths form once pre-checked statement 1). Buttons rendered by a view need their listeners wired in `AFTER.<view>` (the sort buttons were missed once); the starter's `main` click handler only covers the search-page filters. A view that re-renders on every keystroke must restore focus/caret (see `AFTER.batch`). The home hero gradient over a photo banner must start transparent for the top third or it tints the picture. Badge toasts appear on first load of a seeded test (collector, met everyone…); harmless, but they can cover elements in screenshots. After saving My card the app redirects to `#/person/<id>` a moment later — wait for that hash before navigating elsewhere in tests. In Playwright, fields inside closed `<details>` can't be filled — open them first (`document.querySelectorAll('details.fgroup').forEach(d=>d.open=true)`); the regression script on `dev-tools` does this. `.guess__ask` is uppercase via CSS, so text assertions must be case-insensitive (same for `.today__k`). Text-only QR: ~2.2 KB JSON scans reliably from a phone screenshot; photos never go in the QR. The `qa/batch.json` fixture has no playlists — `today_test.py` seeds its own cards via localStorage `bt:v1:batch`.
